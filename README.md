# FineBullion Desk

FineBullion Desk helps manage a gold shop.

## Sale

- Record gold sold to a customer.
- Add gold weight, price, payment, and remaining amount.
- View and change old sales.

Page: `gold_sale.php`

## Exchange

- Record old gold received from a customer.
- Add weight and gold purity.
- See the final gold amount after loss.
- View and change old exchanges.

Page: `gold_exchange.php`

## Buy

- Record old gold bought from a customer.
- Add weight, purity, price, and payment.
- See the remaining amount to pay.
- View and change old purchases.

Page: `gold_buy.php`

## Inventory

- Add gold to the shop.
- See how much gold is available.
- See gold by purity.
- The available amount changes after a sale or exchange.

Page: `matte_color_bangla/inventory.php`

## Expenses

- Record shop expenses.
- Add an expense type, date, and details.
- Search expenses and see expenses for a date range.

Page: `expenses.php`

## Dashboard

- See a quick summary of the shop.
- Check sales, purchases, exchanges, expenses, and available gold.
- Check the summary for today, this week, this month, or selected dates.

Page: `matte_color_bangla/dashboard.php`
